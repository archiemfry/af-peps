AF PEPS — LAUNCH-READY STATIC WEBSITE

FILES
- index.html — website
- products.json — editable product catalogue

ADDING A PRODUCT
1. Open products.json.
2. Add a new object inside the "products" list.
3. Use:
   {
     "name": "Product Name",
     "quantity": "10 mg",
     "price": 40,
     "category": "Research Peptides",
     "description": "Factual research-only description."
   }
4. Save the file.
5. Upload the updated products.json to your hosting.

IMPORTANT
This is a static catalogue website. It does not currently process payments or orders.
Do not activate checkout or advertise products for human use. UK regulatory status and payment-provider acceptance must be checked product-by-product before launch.
